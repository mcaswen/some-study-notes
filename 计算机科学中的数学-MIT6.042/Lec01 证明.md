
- 数学证明：从一系列公理中的一连串逻辑推论，出发的对命题的验证

	- 三大组件：命题、逻辑推论和公理
	
	- 命题：关于对或者错的陈述，两者必有一个成立
	
	- 量词：任意/存在一个等
	
	- 谓词：声称正确/错误的性质
	
	- 全域：取值范围
	
	- 公理：我们假设为真的命题，应该是完整的，一致的。如果推出的命题的正确与否有歧义，就不能称之为公理

- 反证法：为了证明 P 是正确的，假设 P 是错误的，然后从 P 是错误的 这个命题开始推导到矛盾之处

	- 由真值表得出，要 P 反 推出 错误，那么仅当 P 反为错误，即 P 为正确时

- 归纳法：计算机科学中最强大的证明方法之一

	- 描述：若 P(n) 是一个谓词，则对任意自然数n，如果 P(0) 为真 且 P(n) => P(n+1) 为真，则 P(n) 为真
	
	- 如何证明 a => b ？ a为假时，命题总为真；a为真时，需要证明b同时为真
	
	- basic case并不总是 n = 0, 证明 P(b)成立，n >= b时 P(n) => P(n+1) 也行
