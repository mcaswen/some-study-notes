**基于 DOTS 和 ECS 架构构建绝大部分游戏系统**，将数据（单位状态/血量、资源数量等）与行为（单位状态机评估/移动/寻路、资源拾取等）行为分离，增加输入输出确定性的同时利于Job System进行并行计算

**基于 NetCode for Entities 搭建 1v1 RTS 联机框架**，实现 自定义Lobby/Connection/InGame/玩家刷新 链路与可靠 RPC 交互，并设计局域网监听/发布机制与协议

**实现基于 ICommandData 的输入命令环形缓冲**，将玩家输入转换为按 Tick 对齐的命令写入 command buffer，并在预测System组中在客户端和服务端World统一播放，以适配客户端预测/确定性模拟需求

**设计数据导向的 AI 状态机框架**，使用 BlobAsset 构建 FSM 状态图（State/Transition/Enter/Exit），以 DynamicBuffer 作为黑板存储多类型变量，并通过委托模拟虚函数表，Unity.Burst.BurstCompiler手动注册函数指针，实现ECS约束下的多态状态切换/评估与条件/行为调度与扩展

**实现 RTS 指令链路**：将鼠标交互（框选/点击目标）编码为网络可同步的 MovementOrder，通过 RPC 发送至服务端，服务端权威落地到黑板/意图层驱动单位进入 Find/Follow/MoveTo 等状态，实现“指令→AI→移动”的端到端闭环。

**实现移动系统分层与服务端权威推进**：通过调用Navmesh API 计算寻路期望速度并在服务端推进路径点，由单位物理移动系统在服务端基于 Unity.Physics 和自研碰撞检测算法进行碰撞过滤与分离

**设计高性能 3D 碰撞检测算法**：基于 SAT分离轴定理 和 Burst 优化进行单位间的碰撞检测（包括面-面、边-边的最小投影距离求解），通过ClipPlane与裁剪算法生成精确接触点，并使用Unsafe原始指针和轻量自定义结构体，支持千级单位的高性能碰撞计算
